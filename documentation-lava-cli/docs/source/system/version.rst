``lava system version``
=======================

Intended to show the LAVA server version.

.. warning:: This command is **not implemented yet**. Invoking it returns a
   "not implemented" error and makes no network calls.

To see the *CLI* version rather than the server version, use the global
``--version`` flag:

.. code-block:: bash

   lava --version
