workers commands
=================

The ``workers`` commands inspect and manage the LAVA *shared workers* that
are accessible to your subscription. A worker is the machine that dispatches
jobs to the devices attached to it.

You can list workers, show a worker's details and place a worker into
maintenance. Commands for managing worker configuration and environment are
present for compatibility but are not yet implemented.
